# Evapotranspiration Prediction using Machine Learning

## Overview

This project predicts evapotranspiration using machine learning techniques based on meteorological and satellite-derived data.

## Features

- Data preprocessing
- Feature engineering
- Random Forest Regression
- XGBoost Regression
- Model evaluation
- Performance visualization

## Technologies

- Python
- Pandas
- NumPy
- Scikit-Learn
- XGBoost
- Matplotlib
- Jupyter Notebook

```bash
pip install -r requirements.txt
```
